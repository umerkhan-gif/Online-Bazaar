# 🛒 Online-Bazaar

### A Django-Based E-commerce Web Application

Online-Bazaar is a multi-page e-commerce web application built with **Python and Django**. The project provides a complete online shopping experience with products, categories, product details, shopping cart, user authentication, and order management.

---

## ✨ Features

* 🏠 Professional homepage
* 🛍️ Product listing
* 📦 Product categories
* 🔎 Product search
* 📄 Product detail pages
* 🛒 Shopping cart
* 👤 User registration and login
* 📋 Order management
* 🖼️ Product images
* 🎞️ Homepage image slider
* 📱 Responsive web design
* 🔐 Django authentication
* 🗄️ Database integration

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/umerkhan-gif/Online-Bazaar.git
```

### 2. Open the project

```bash
cd Online-Bazaar
```

### 3. Install Django

```bash
pip install django
```

### 4. Run migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Start the development server

```bash
python manage.py runserver
```

Open the project in your browser:

```text
http://127.0.0.1:8000/
```
